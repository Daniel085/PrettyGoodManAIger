# examples/

**Fictional, clearly-labeled worked examples** — so you can see what a *good* dossier looks like
before you have data of your own. None of these are real people. They're safe to keep in the public
repo (and are the only "filled-in" dossiers that ship).

| File | Shows |
|------|-------|
| `example-person-dossier.md` | Alex Chen, Senior PM — discovery strength, exec-presence growth edge |
| `example-boss-dossier.md` | Sam Rivera, Director — data-driven archetype, currencies, love language |
| `example-decision.md` | Scoping down v1 — a decision logged *before* the outcome |

Try the system with zero setup: run `/prep-1on1` against `example-person-dossier.md`, or `/prep-boss-1on1`
against `example-boss-dossier.md`.

> Your *real* dossiers go in `../people/`, `../boss/`, `../decisions/` — which are gitignored and stay
> local. Don't add real data here.
